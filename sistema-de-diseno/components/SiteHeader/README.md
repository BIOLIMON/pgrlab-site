# SiteHeader

Cabecera: marca del laboratorio a 40px con el nombre en serif, y navegación en `mono` y minúsculas, donde la página actual se marca como ruta `~/`.

- **El consumidor provee** la ruta actual (`aria-current="page"`) y el idioma activo.
- Sin fondo propio ni sombra; solo una línea `rule` abajo. No queda fija al hacer scroll.

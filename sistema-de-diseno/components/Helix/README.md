# Helix

Doble hélice horizontal que gira despacio; la hebra delantera en el color de línea, la trasera y los peldaños en `ink-faint`, y pares complementarios A–T / G–C en `ink-muted`.

## Uso

```js
PGR.Helix(container, { rows: 9, line: "redes" });
```

- **El consumidor provee** un contenedor a lo ancho; el alto lo fija `rows` (7–11, impar).
- Úsala como separador entre secciones largas o en el pie, nunca más de una por página.
